# 个人日程 V8.7

一个可以直接部署到 GitHub Pages 的中文个人日程网站。

## 功能

- 首页黄历：公历、农历、节气或节日、十二时辰吉凶
- 首页固定六行计划板：点击“＋”进入整板编辑，填写6组时间和内容后一次保存
- 计划板日期可直接切换，每次打开默认今天
- 三色日历：个人（蓝色）、活动（绿色）、客房（黄色）
- 客房事项支持入住日期和退房日期
- 顶部导航精简为“首页日历”和“愿望清单”
- 愿望清单支持 Emoji、中文标题和详细计划
- 点击日历日期可以选择心情Emoji并写当日日记
- 日历事项Emoji改为丰富的点选面板，无需手动输入
- 日记与日历事项统一使用精选的20个Emoji，并按照选定顺序排列
- 今日安排保存提示简化为“已保存”
- 今日安排每行支持完成勾选，并可一键清空当前日期的六行内容
- 今日安排会自动移除超过30天的旧记录，云端旧记录也会同步清理
- 愿望清单显示愿望已存在的时间
- 愿望可反复复制成蓝色或绿色日历计划，原愿望继续保留
- 点击“实现”并确认后移除愿望，同时显示祝贺提示
- 日记与事项Emoji扩充为30个，并按选定顺序排列
- 今日安排调整为6行，底部增加四个日期独立的菜品格
- 新增“我的菜谱”：记录菜名、做法、可选照片，支持查看、编辑和删除
- 菜品照片会在浏览器中自动压缩后同步，不需要额外启用Firebase Storage
- 首页菜品格可从菜谱中选菜、选择日期、更换或移除
- 首页与月历尺寸重新压缩，常见电脑在100%缩放下能显示更多内容
- 日记Emoji在月历中加大显示，整体改为温暖的奶油、薄荷与淡紫配色
- 日历事项表单精简为事项颜色、日期、标题与内容，不显示冗余说明
- 日记可按月、按年或全部导出为 `.docx` Word 文件
- Firebase实时同步与本地缓存
- 云同步兼容修复：菜谱与菜品安排复用原有三个Firestore集合，无需修改安全规则
- 自动迁移V8.5中已经保存在本机的菜谱与菜品安排
- 菜谱支持牛肉、鸡肉、猪肉、海鲜、其他五种分类和颜色标识，旧菜谱默认归入其他
- 首页选菜按五种肉类分组，已安排菜品同时显示分类色点
- 每张菜谱右上角可一键加入今天第一个空闲菜品格，四格满时会提示且不会覆盖
- 手机、平板和电脑自适应

## 部署

将本目录中的全部文件复制到 GitHub 仓库根目录，然后 Commit 并 Push。GitHub Pages 完成部署后即可使用。

`config.js` 已保留当前项目所需的 Firebase Web 配置，不需要修改数据库接口。

## 旧数据迁移

新版第一次成功连接 Firebase 时，会删除旧版中不属于个人日程的数据类型，并且不再读取旧版浏览器缓存。新版创建的日程、每日计划、日记和愿望不会被清理。

## 第三方组件

- `lunar-javascript`：农历与传统黄历计算，MIT License
- `docx`：浏览器端生成 Word 文档，MIT License

对应许可证位于 `js/vendor/`。
